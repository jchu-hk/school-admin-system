# Agent KPI定义

## DEV Agent
| KPI | 目标 | 测量 |
|-----|------|------|
| 功能完成率 | ≥ 90% | Issue完成数/分配数 |
| 代码质量 | 无lint错误 | CI lint通过 |
| PR审查通过率 | ≥ 80% | 一次通过比例 |

## DEVOPS Agent
| KPI | 目标 | 测量 |
|-----|------|------|
| 部署成功率 | ≥ 95% | 成功/总部署 |
| 问题修复时间 | ≤ 2小时 | 平均修复时间 |
| 验收通过率 | 100% | CHECKER通过/总部署 |

## QA Agent
| KPI | 目标 | 测量 |
|-----|------|------|
| 测试用例覆盖率 | ≥ 80% | 核心功能覆盖 |
| 缺陷发现率 | - | 上线后Bug数 |
| 复验准确性 | ≥ 95% | 复验正确/总复验 |

## CHECKER Agent
| KPI | 目标 | 测量 |
|-----|------|------|
| PR审查时间 | ≤ 30分钟 | 平均审查时间 |
| 缺陷漏检率 | ≤ 5% | 上线后发现/审查发现 |
| 验收准确性 | 100% | 正确通过/错误通过 |

## PM Agent
| KPI | 目标 | 测量 |
|-----|------|------|
| 任务流转效率 | 任务阻塞时间≤2小时 | 平均等待时间 |
| 流程执行率 | 100% | 按流程执行/总任务 |
| 用户满意度 | - | 用户反馈 |
