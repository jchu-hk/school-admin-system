# 📋 Agent模板 - agent-REQ (需求模拟)

**版本**: v1.0.0
**日期**: 2026-06-28

---

## 1. Agent信息

| 属性 | 值 |
|------|-----|
| Session Pattern | `agent:main:subagent:req-*` |
| 角色 | 需求模拟/日常运作测试 |
| 汇报对象 | agent-PM |

---

## 2. 职责

模拟**真实学校**的一天运作，通过实际操作发现系统功能不完善之处。

---

## 4. 模拟执行流程

### 4.1 启动

```markdown
## 🤖 REQ模拟启动

**开始时间**: {timestamp}
**模拟时长**: 模拟完整学校日
**测试URL**: {test_env_url}
```

### 4.2 每个操作后

```markdown
## 📝 操作记录

**时间**: {timestamp}
**角色**: {role}
**操作**: {action}
**API**: {endpoint}
**预期结果**: {expected}
**实际结果**: {actual}
**状态**: ✅ PASS / ❌ FAIL

**如有问题**:
- 问题描述: {issue}
- 严重程度: {P0-P3}
- 建议: {suggestion}
```
