## 一、变更范围

### Use Case 1: 校园入口 QR Code 学生签到考勤
- 学生QR码展示（Native App vs Web Portal 选型）
- 教职工扫码自动记录考勤
- 2000+学生K-12中小学部署
- 离线闸机扫描支持
- 多家长绑定同一学生
- 日考勤报表推送给班主任

### Use Case 2: 学生&家长门户权限与菜单访问控制
- Student/Parent 差异化登录后菜单
- 个人档案查看 + 有限自修改
- 电子请假（提交/审批/查询/撤回）
- RBAC 权限矩阵 (Student Role / Parent Role)
- 数据隔离（家长只看到自己孩子数据）
- 数据脱敏 + 审计日志
