## 3. 测试策略

### 3.1 测试层级

```
┌─────────────────────────────────────┐
│      系统级测试 (System Test)       │
│  - 完整业务流程测试                  │
│  - 端到端E2E测试                    │
│  - 性能和负载测试                    │
└─────────────────────────────────────┘
                  ↑
┌─────────────────────────────────────┐
│      集成测试 (Integration Test)     │
│  - 模块间接口测试                    │
│  - 数据流测试                       │
│  - API集成测试                      │
└─────────────────────────────────────┘
                  ↑
┌─────────────────────────────────────┐
│      模块级测试 (Module Test)        │
│  - 单个功能模块测试                  │
│  - 功能完整性验证                    │
│  - 边界条件测试                     │
└─────────────────────────────────────┘
                  ↑
┌─────────────────────────────────────┐
│      单元测试 (Unit Test)            │
│  - 函数/方法级测试                   │
│  - 开发者自测                       │
└─────────────────────────────────────┘
```

### 3.2 测试类型

| 类型 | 说明 | 工具 |
|------|------|------|
| 功能测试 | 验证功能是否符合规格 | Playwright |
| 性能测试 | 验证系统性能指标 | k6, JMeter |
| 安全测试 | 验证安全性和权限 | 手动测试 |
| 兼容性测试 | 跨浏览器/设备测试 | BrowserStack |
| 回归测试 | 验证缺陷修复不引入新问题 | Playwright |
