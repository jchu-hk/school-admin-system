# UI 界面设计规范
## 教师招聘管理模块 (Module 14)
## v1.0.0 | 2026-06-30

---

## 1. 概述

本文档定义教师招聘管理模块的用户界面设计规范，包括页面布局、表单设计、列表视图和用户交互流程。

---

## 2. 设计原则

| 原则 | 说明 |
|------|------|
| **一致性** | 遵循现有系统设计规范，保持视觉一致性 |
| **简洁性** | 减少认知负荷，突出核心操作 |
| **响应式** | 支持桌面端和平板端访问 |
| **可访问性** | 符合WCAG 2.1 AA标准 |
| **移动优先** | 优先考虑移动端用户体验 |

**筛选条件:**
- 状态: 全部 / 草稿 / 已发布 / 已暂停 / 已关闭

- 零佣类型: 全部 / 全职 / 兼职 / 合约

**表格列:**
| 列名 | 说明 | 排序 |
|------|------|------|
| 职位名称 | 职位标题 | 是 |
| 学科 | 教授学科 | 是 |
| 雇佣类型 | FULL_TIME/PART_TIME/CONTRACT | 是 |
| 状态 | 职位状态（带颜色标识） | 是 |
| 申请数 | 该职位收到的申请数量 | 是 |

**状态标识:**
- 草稿: 灰色标签
- 已发布: 绿色标签
- 已暂停: 黄色标签
- 已关闭: 灰色标签

**表单验证:**
- 所有必填字段不能为空
- 薪资最低值不能大于最高值

- 任职要求至少填写1条

- 保存草稿: 保存为DRAFT状态，可继续编辑
- 预览: 弹出预览窗口，展示职位详情
- 发布: 将职位状态改为PUBLISHED，正式发布

## 9. 响应式设计

### 9.1 桌面端 (≥1024px)
- 完整显示所有列和功能
- 使用侧边栏导航
- 表格支持横向滚动

### 9.2 平板端 (768px - 1023px)
- 隐藏部分次要列
- 简化筛选条件
- 使用折叠式菜单

### 9.3 移动端 (<768px)
- 使用卡片式布局替代表格
- 筛选条件使用抽屉式弹窗
- 简化表单布局
- 增大点击区域

## 10. 交互规范

### 10.1 加载状态
- 列表加载: 显示骨架屏或加载动画
- 表单提交: 显示加载中提示，禁用提交按钮
- 文件上传: 显示上传进度条

### 10.2 错误提示
- 表单验证错误: 在字段下方显示红色提示
- API错误: 显示Toast通知，3秒后自动消失
- 网络错误: 显示重试按钮

### 10.3 成功提示
- 操作成功: 显示绿色Toast通知
- 提交成功: 跳转至详情页或列表页
- 显示成功图标和简短文字

### 10.4 确认对话框
- 删除操作: 显示确认对话框
- 状态变更: 对于不可逆操作显示确认
- 二次确认: 重要操作需要再次确认

---

## 11. 可访问性

### 11.1 键盘导航
- 所有交互元素支持Tab键导航
- 表单支持Enter键提交
- 模态框支持Esc键关闭

### 11.2 屏幕阅读器
- 所有图片提供alt文本
- 表单字段提供label
- 使用ARIA属性增强可访问性

### 11.3 对比度
- 文本与背景对比度≥4.5:1
- 重要信息使用高对比度颜色
- 避免仅使用颜色传达信息
