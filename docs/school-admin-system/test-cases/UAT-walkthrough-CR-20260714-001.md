1. 打开根地址，按角色进入对应入口：

## 👨💼 角色一：school_director（校务主任 / 管理员）

> 目标：从管理视角确认两个新模块整体可用、数据可查、越权不可达。

| # | 试用步骤 | 你在做什么 | 期待看到 | 反馈记录 |
|---|---------|-----------|---------|---------|
| D1 | 用 `school_director` 登录 `{root}/school-admin/` | 进入管理后台 | 能正常登录，看到完整后台菜单（含用户管理、班级管理、财务审计、请假审批、考勤报表等） | |
| D2 | 打开「考勤日报」 | 查看全校/各班签到情况 | 日报含应到/已签/迟到/缺勤以及未签到名单 | |
| D3 | 打开「请假审批」 | 处理一条 >3 天的请假 | 看到两级审批（班主任初审→你终审）流程，可执行终审 | |
| D4 | 打开「审计日志」 | 检索修改/请假/越权记录 | 能看到关键操作的审计记录，且敏感字段为脱敏显示 | |
| D5 | 尝试用一个学生账号（可让 QA 协助）访问后台管理 URL | 验证越权拦截 | 学生身份访问后台管理被拒绝（403/无权访问） | |

**试用要点**：校务主任是系统最终管理者，请特别关注「报表准确性」和「审计可追溯性」是否满足学校管理需求。

## 👩‍🏫 角色二：teacher（教职工 / 班主任）

> 目标：体验从扫码签到到审批到看日报的完整教学工作流。

| # | 试用步骤 | 你在做什么 | 期待看到 | 反馈记录 |
|---|---------|-----------|---------|---------|
| T1 | 用 `teacher` 登录 `{root}/school-admin/` | 进入教职工后台 | 能正常登录，进入工作台/仪表板 | |
| T2 | 学生展示 QR 码时，用扫码终端/摄像头扫描 | 完成一次真实签到 | 屏幕显示学生姓名、班级、签到时间、状态 | |
| T3 | 对同一码再扫一次（或学生 5 分钟内换新码再扫） | 验证防重/限流 | 被明确提示「二维码已被使用」或「请勿重复签到」 | |
| T4 | 等待学生码过期后再扫一次 | 验证过期拦截 | 被提示「二维码已过期」，需要学生刷新码 | |
| T5 | 查看「考勤日报」 | 上班查只看班级到勤 | 看到所带班级的应到/已签/迟到/缺勤名单 | |
| T6 | 审批一条学生提交的 ≤3 天请假 | 完成学生请假审批 | 审批通过后状态变为 approved，学生收到通知 | |

**试用要点**：班主任天天用扫码和审批，请评估「扫码效率」「重复/过期拦截的提示是否清晰」「日报是否符合出勤管理习惯」。

## 🧑‍🎓 角色三：student（学生）

> 目标：从学生本人视角体验进门扫码、看档案、改联系方式、请假。

| # | 试用步骤 | 你在做什么 | 期待看到 | 反馈记录 |
|---|---------|-----------|---------|---------|
| S1 | 用 `student` 登录 `{root}/portal/student` | 进入学生门户 | 看到学生角色菜单（个人档案、我的QR码、电子请假、考勤、成绩、课表等） | |
| S2 | 打开「我的QR码签入」`{root}/attendance/qr` | 准备进门签到 | QR 码自动显示 + 30 秒倒计时自动刷新 | |
| S3 | 让教职工/同学扫码 | 完成进门签到 | 收到「签到成功」提示 | |
| S4 | 打开「个人档案」 | 查看/修改个人信息 | 学号姓名等锁死，手机号/邮箱/地址可改；改联系方式保存后立即生效 | |
| S5 | 打开「电子请假 → 提交请假」 | 请一天事假 | 填写后提交成功，状态显示 `pending` | |
| S6 | 在「请假记录」里点「撤回」 | 撤回还没审批的假 | pending 的假可撤回，变 `cancelled` | |

**试用要点**：学生最关心「QR 码是否好使」「请假是否简单」「改联系方式是否顺手」。QR 码 30 秒刷新是否会造成不便，请如实反馈。

## 👨‍👩‍👧 角色四：parent（家长）

> 目标：确认家长只看到自己孩子，能代请假，数据被保护（脱敏）。

| # | 试用步骤 | 你在做什么 | 期待看到 | 反馈记录 |
|---|---------|-----------|---------|---------|
| P1 | 用 `parent` 登录 `{root}/portal/parent` | 进入家长门户 | 看到家长角色菜单（子女档案、子女考勤、代请假、子女成绩、校历、缴费等），且**看不到**学生专属的「我的QR码」「课表」 | |
| P2 | 打开「子女档案」 | 看孩子信息 | 全部只读，无编辑按钮；手机号显示 `****4567`、邮箱 `c***@xxx`、地址门牌掩码 | |
| P3 | 打开「子女考勤」 | 看孩子到勤 | 只看到自己孩子的考勤记录，无其他学生信息 | |
| P4 | 打开「电子请假 → 代子女提交」 | 替孩子请假 | 选择自己孩子可提交，系统标记为家长代提交 | |
| P5 | （重点）尝试打开「考勤/成绩/请假」并切换到非本人关联的学生 | 数据隔离自测 | 页面无其他孩子选项；即使直连 URL/接口也返回无权访问 | |

**试用要点**：家长最担心「隐私与孩子数据只给我看」。请重点反馈：①脱敏显示是否直观；②是否确实看不到别人家孩子；③代请假是否好用。
