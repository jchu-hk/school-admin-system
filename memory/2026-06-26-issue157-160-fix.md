## ✅ Issue #160 - 家长查询提交失败

### 问题分析
**根本原因**: 前端与后端字段名不匹配

| 前端发送 | 后端期望 | 说明 |
|---------|---------|------|
| `type` (bus/fee/grade/leave/other) | `category` (academic/attendance/discipline/health/finance/general) | 字段名和值域不同 |
| `title` | `subject` | 字段名不同 |
| 无`parentId` | `parentId` (required) | 缺少必需字段 |

### 修复措施

#### 1. 前端修复 (`school-admin-frontend/src/pages/InquiryPage.tsx`)
- 添加字段映射表`categoryMap`
- 从localStorage获取当前用户ID作为parentId
- 转换字段名和值：
  - `type` → `category`
  - `title` → `subject`

```typescript
const categoryMap: Record<string, string> = {
  bus: 'attendance',
  fee: 'finance',
  grade: 'academic',
  leave: 'attendance',
  other: 'general'
}

await inquiryApi.createInquiry({
  parentId: user?.id || 'default-parent-id',
  category: categoryMap[data.type] || 'general',
  subject: data.title,
  content: data.content,
  priority: data.priority,
  channel: 'app'
})
```

#### 2. API层修复 (`school-admin-frontend/src/api/inquiry.ts`)
- 适配后端接口字段格式
- 发送JSON而非FormData

#### 3. 后端修复 (`apps/backend/src/modules/inquiry/dto/inquiry.dto.ts`)
- `parentId`改为可选字段（`@IsOptional()）
- 如果前端未提供，自动使用当前用户ID

```typescript
@ApiProperty({ description: '家长ID', required: false })
@IsOptional()
@IsUUID()
parentId?: string;
```

#### 4. Service层修复 (`apps/backend/src/modules/inquiry/inquiry.service.ts`)
- 自动使用userId作为parentId备用

```typescript
const parentId = dto.parentId || userId;
```
