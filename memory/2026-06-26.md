### fix(#153): 学生管理班级筛选器数据不完整

**优先级**: P0 - 立即处理

**问题**: 
- 学生列表中有"中三A班"学生
- 但班级筛选dropdown只显示1A, 2A
- 导致无法筛选中文班级

**根因**:
- 后端 `/api/users/classes` 返回格式不正确
- 直接返回数组: `["1A", "2A", "中三A班", ...]`
- 前端期望: `{data: ["1A", "2A", "中三A班", ...]}`
- 当前端解析 `response.data.data` 时得到 `undefined`
- 触发fallback硬编码列表，只有英文班级

**修复**:
```typescript
// UserController.getClasses()
async getClasses() {
  const classes = await this.userService.getClasses();
  return { data: classes };
}
```

**验证**:

}
