**范围**：Human-Testing 2026-07-31 发现的 6 个前端 P0，纯前端最小改动，无后端/DB 改动。

### #295 学生管理-编辑学号未回填
- 根因：`StudentPage.tsx` `openEditModal()` reset 遗漏 `student_id`。
- 修复：reset 补 `student_id: student.student_id || ''`；`StudentForm` 加 `isEdit` prop，编辑时学号 readOnly（学号自动生成不可修改）。

### #296 学生管理-Delete 图标对所有记录可见
- 根因/说明：系统**无 draft 状态**（enum=active/graduated/withdrawn/transferred，DB 无 draft）。
- 修复：`canDeleteStudent(status)` 仅 active 显示删除按钮。已在 issue #296 说明，请 PM/BA 确认是否需要 draft 状态。

### #297 学生管理-编辑无法改 status
- 根因：编辑表单/ schema/ payload 完全没有 status 字段；后端 UpdateStudentDto 已支持。
- 修复：schema + `DEFAULT_FORM_VALUES` + 表单“状态”下拉 + reset 回填 + 提交 payload 补全。

### #299 人工录入出勤-表格缺班级列
- 根因：`AttendancePage.tsx` 批量表只有 #/学号/姓名/状态/到校时间/备注。
- 修复：新增“班级”列，逐行显示 `record.classId`。

### #300 人工录入出勤-生成确认预览无响应
- 根因：manual tab 从不渲染 `error` 状态（错误只在 overview tab 显示），预览失败被吞掉。
- 修复：manual tab 在预览按钮上方加 error banner（红条 + XCircle）。

### #303 考试管理-新增考试 Save 无反应
- 根因：`src/api/exam.ts` 用 `localStorage.getItem('auth_token')` 读 token，但系统实际存于 `'token'` 键 → Bearer null → 401。
- 修复：统一改用 `getToken()`，7 处全部替换。
- 备注：`auth_token` 误用同样存在于 course/settings/finance/budget/dse（#301/302/304/305 相关），本次仅按 #303 修 exam。
