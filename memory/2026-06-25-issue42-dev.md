## 核心业务逻辑

### 48小时撤回机制
```typescript
// 提交时设置可撤回截止时间
record.canRevokeUntil = new Date(Date.now() + 48 * 60 * 60 * 1000)

// 撤回时检查
if (!record.canRevokeUntil || new Date() > record.canRevokeUntil) {
  throw new BadRequestException('Revoke period has expired (48 hours)')
}
```
